Browser Window Active on Desktop

Login di jendela browser yang terbuka. Cookie akan disinkronkan secara real-time. Jika selesai, klik tombol konfirmasi di bawah atau tutup jendela browser.

Gunakan browser apa saja (Chrome, Firefox, Brave, Edge). Login seperti biasa di tab target, lalu jalankan script berikut di DevTools Console (F12) untuk sinkronisasi otomatis ke Spectra MCP: 

fetch("http://127.0.0.1:8000/api/auth/cookies/import", {
  method: "POST",
  headers: {"Content-Type": "application/json"},
  body: JSON.stringify({
    project: "",
    domain: window.location.hostname,
    raw_cookie: document.cookie
  })
}).then(r => r.json()).then(d => alert("✅ Berhasil sync " + d.cookie_count + " cookies ke Spectra MCP!"))
.catch(e => {
  navigator.clipboard.writeText(document.cookie);
  alert("⚠️ Mixed-content: Cookie otomatis disalin ke clipboard! Paste di tab Direct Paste.");
});
💡 Tips Pentester (HttpOnly Cookie): Jika cookie autentikasi menggunakan flag HttpOnly (tidak bisa dibaca oleh document.cookie), cukup buka tab Network di DevTools, klik kanan salah satu request target → Copy as cURL, lalu paste di tab 3. Direct Paste di sebelah!
